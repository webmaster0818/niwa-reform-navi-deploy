堺市の危険ブロック塀等撤去工事補助金｜上限15万円の条件と申請の流れ

堺市は、不特定の人が通行できる道や公園等に面した高さ60cm超の危険なブロック塀等をすべて撤去する工事に補助しています。補助額は、15万円、「長さ×31,000円×2/3」、「撤去費×2/3」のうち最も低い額で、敷地が接する道路ごとに計算します。令和8年度の申し込みは令和9年1月29日（金）までで、予算の状況により早く終了する場合があります。市の公式ページ（2026年11月3日確認）の記載をもとに整理します。

最終更新日：2026-11-03（堺市の公式ページを同日に確認）

本ページの見方

  • 金額・条件・受付状況は、2026-11-03に堺市の公式ページで確認した内容です。

  • 個別の塀が補助の対象になるかどうかの判定は、当サイトでは行っていません。

補助の内容と上限額

区分補助の内容
補助額次のうち最も低い額（1,000円未満切り捨て）。敷地の接する道路ごとの額。・150,000円　・撤去する塀の長さ（m）×31,000円（基準額）×2/3　・撤去に要する費用×2/3

対象になる塀と工事

対象になる塀

次の1〜4すべてに当てはまる塀。1. 不特定の人が利用する道や公園等に面している　2. 補強コンクリートブロック造（ブロック塀）または組積造等　3. 高さが60cmを超える　4. 危険なもの（市の点検表で不適合が1つ以上ある、または日本建築学会「既存コンクリートブロック塀耐震診断指針(案）」で安全と確認できないもの）

対象になる工事

道や公園等に面する危険ブロック塀等をすべて撤去する工事（土留め部分は残すこともできます）。

塀の構造基準（高さ2.2メートル以下、控壁、基礎など）は、建築基準法施行令第62条の8の解説で条文を引用して整理しています。

申請の流れ

  1. 1交付申請（申請書、登記事項証明書等、見積書、耐震診断結果等の報告書と写真、工事内容が分かる図面、資金計画書、工事施工者の建設業許可証の写しなど）
  2. 2交付決定後に工事請負契約、着手届・契約書・工程表の提出
  3. 3完了実績報告書の提出（完了写真、領収書の写し、収支決算書など）
  4. 4補助金交付請求

出典：堺市公式ページ（2026-11-03 確認）

申請前に確認しておきたい点

  • コンクリートブロック塀の点検表は、高さ2.2m以下、壁の厚さ、鉄筋、控壁、基礎、傾き・ひび割れ、ぐらつき、土止め壁を兼ねていないか、の8項目です。
  • 代理受領を行う場合は、代理受領予定届出書と代理受領に係る委任状を提出します。
  • 分譲マンション等の区分所有建物では、工事を行うことを決議した理事会または総会の議事録が必要です。
